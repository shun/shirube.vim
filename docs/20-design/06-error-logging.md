# エラー / ログ / 回復

## エラー分類
- 解析エラー: バッファ行の形式不正、未知 ID、空名など。
- バリデーションエラー: 同名衝突、パス正規化後の重複など。
- Adapter エラー: IO 失敗、権限不足、パス不存在など。
- UI エラー: フローティング/Popup 作成失敗など。

## 失敗時の振る舞い
- エラー発生時は Action 実行を即時中断する。
- 失敗した Action と理由を通知する。
- バッファは再描画せず、ユーザーが原因を確認できる状態を維持する。

## ログ出力
- Deno 側でエラーを集約し、Vim 側のメッセージ領域に通知する。
- `:messages` で確認できる形式を基本とする。
- headless 実行では `v:errors` を利用して失敗を検知する。
